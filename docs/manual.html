01安装

系统要求

  • Python 3.8+（推荐 3.10+）
  • 操作系统：Windows 10/11、Linux（Ubuntu/Debian/CentOS/Arch）、macOS 11+
  • 无需安装任何第三方包 — 全部使用 Python 标准库

方式一：直接使用（推荐）

下载 ZIP 压缩包，先解压整个文件夹，然后启动：

# Windows（重点！）
1. 右键 rtlens_v2.1.0.zip → "解压到当前文件夹"
2. 进入解压后的文件夹
3. 双击 start.bat
4. 浏览器自动打开 http://127.0.0.1:8765

# Linux / macOS
unzip rtlens_v2.1.0.zip
cd rtlens_v2.1.0
chmod +x start.sh
./start.sh
⚠ Windows 用户必读：
  • 必须先解压 ZIP，不要在压缩包内直接双击 start.bat（会找不到 rtlens 包）。
  • 不要用 Win+R 运行 python -m rtlens quickstart — Win+R 从用户主目录执行，找不到 rtlens 模块，窗口一闪就关。请用 cmd 或 PowerShell，先 cd 到解压目录再运行。
  • 需要 Python 3.8+。如果没装 Python，start.bat 会自动打开下载页（安装时勾选 "Add python.exe to PATH"）。
  • start.bat 弹出的黑色窗口请保持打开，关闭即停止服务。

方式二：pip 安装

cd rtlens
pip install -e .

# 验证安装
rtlens --version
# 输出: rtlens v2.1.0

方式三：手动运行

打开 cmd / PowerShell / 终端，cd 到解压目录后运行：

cd C:\path\to\rtlens      :: Windows
cd /path/to/rtlens         :: Linux/macOS

python -m rtlens --version
python -m rtlens quickstart
提示：方式一最简单 — 解压后双击 start.bat（Windows）或 ./start.sh（Linux/macOS），浏览器自动打开 Web UI 仪表盘。如果浏览器没有自动弹出，手动访问 http://127.0.0.1:8765。

02快速上手

30 秒速通

📍 Web UI 模式

最简单的使用方式 — 浏览器打开可视化仪表盘：

python -m rtlens quickstart

浏览器自动打开 http://127.0.0.1:8765，可以看到索引统计、符号搜索、模块详情等。

⌨️ CLI 命令行模式

快速索引一个 Verilog 工程：

python -m rtlens index ./my_project
python -m rtlens query ./my_project counter
python -m rtlens parse ./my_project/top.v

一键启动器

v2.1.0 新增了一键启动脚本，无需记忆命令：

Windows: start.bat

双击运行即可。自动检测 Python（py / python / python3）、验证 rtlens 包存在，浏览器自动打开 Web UI。若无 Python 会自动打开下载页。

Linux/macOS: start.sh

chmod +x start.sh
./start.sh

索引你的 Verilog 工程

# 索引整个工程目录
python -m rtlens index /path/to/your/project

# 输出示例:
# Indexed 8 files
#   Modules:   7
#   Ports:     50
#   Signals:   39
#   Params:    25
#   Instances: 7

# 启动 Web UI 并索引指定工程
python -m rtlens web --root /path/to/your/project

交互式终端（TUI）

python -m rtlens tui --root /path/to/your/project

# 进入交互式终端后：
rtlens> stats          # 查看索引统计
rtlens> find counter   # 搜索符号
rtlens> module alu      # 查看模块详情
rtlens> tree soc_top   # 查看例化层级树
rtlens> quit            # 退出

03VS Code 集成（LSP）

RTLens 实现了完整的 LSP 协议，可直接集成到 VS Code / Neovim / Emacs 等编辑器。

配置步骤

  1. 确保 rtlens 已安装（pip install -e . 或 python -m rtlens --version 可用）
  2. 在 VS Code 中安装任意 Verilog 语法高亮扩展（如 "Verilog-HDL/SystemVerilog"）
  3. 配置 LSP 服务器

方法 A：使用 coc.nvim（Neovim）

// ~/.config/nvim/coc-settings.json
{
  "languageserver": {
    "rtlens": {
      "command": "python",
      "args": ["-m", "rtlens", "lsp"],
      "filetypes": ["verilog", "systemverilog"],
      "rootPatterns": [".git/", "Makefile", "*.f"]
    }
  }
}

方法 B：使用 VS Code LSP 扩展

创建一个简单的 VS Code 扩展，或使用 vscode-languageclient 配置：

// .vscode/settings.json (参考模板，见 vscode/settings.json)
{
  "rtlens.path": "python",
  "rtlens.args": ["-m", "rtlens", "lsp"],
  "files.associations": {
    "*.v": "verilog",
    "*.sv": "systemverilog",
    "*.vh": "verilog",
    "*.svh": "systemverilog"
  },
  "editor.semanticHighlighting.enabled": true,
  "editor.inlayHints.enabled": "on"
}

方法 C：使用 eLinx IDE

# 在 eLinx 工程根目录创建配置文件
python -m rtlens lsp --stub-dir /path/to/elinx/stubs

包含路径配置

如果你的工程使用了 \`include 指令，需要指定搜索路径：

python -m rtlens lsp -I /path/to/includes -I /path/to/rtl

语义 Token 类型

13 种 token 类型为编辑器提供精确的语义高亮：

Token 类型

  • namespace — module/package 名
  • type — 模块类型引用
  • class — class 名
  • function — function/task 名
  • variable — 信号/wire/reg
  • parameter — parameter/localparam
  • keyword — Verilog 关键字

Token 修饰符

  • declaration — 声明处
  • definition — 定义处
  • readonly — parameter/localparam
  • static — 静态方法
  • modification — 赋值目标
  • documentation — 文档注释

09配置（ServerConfig）

通过 LSP 的 initializationOptions 传入配置（参考 rust-analyzer 设计）：

{
  "rtlens": {
    "diagnostics": {
      "enable": true,
      "experimental": false,
      "maxItems": 200,
      "disabled": ["unused_signal", "unknown_module"]
    },
    "completion": {
      "addCallParenthesis": true,
      "snippets": true,
      "autoImport": true
    },
    "indexing": {
      "autoIndex": true,
      "exclude": ["**/sim/**", "**/tb/**", "**/.git/**"],
      "fileTypes": [".v", ".sv", ".vh", ".svh"]
    },
    "formatting": {
      "style": "kr",
      "indentSize": 4,
      "alignPorts": true,
      "maxBlankLines": 1
    },
    "elinx": {
      "stubDir": null,
      "autoLoadConstraints": true
    },
    "logLevel": "info"
  }
}
说明：diagnostics.disabled 可以禁用特定诊断类型。indexing.exclude 支持 glob 模式排除目录。formatting.style 支持 "kr"（K&R 风格）和 "allman"（Allman 风格）。

10故障排除

端口被占用

[error] Port 8765 already in use. Try --port 8766

使用 --port 参数指定其他端口，或使用 start.bat / start.sh 自动选择可用端口。

Python 未找到

确保 Python 3.8+ 已安装并加入 PATH。检查：

python --version
# 或
python3 --version

文件未被索引

  • 确保文件扩展名为 .v、.sv、.vh 或 .svh
  • 检查 indexing.exclude 配置是否排除了该目录
  • 使用 python -m rtlens index <目录> 查看实际索引结果

中文注释乱码

确保文件使用 UTF-8 编码。RTLens 使用 encoding="utf-8", errors="replace" 读取文件，会自动替换无法解码的字符。

LSP 服务器无响应

  • 检查编辑器的 LSP 输出面板是否有错误信息
  • 确保 python -m rtlens lsp 能正常启动（在终端中测试）
  • 大型工程首次索引可能需要几秒钟，等待索引完成后再操作

Windows VT100 颜色码问题

TUI 在 Windows 10+ 上自动启用 VT100 转义码。如果看到乱码（如 ←[36m），运行 rtlens tui 前执行：

REG ADD HKCU\CONSOLE /v VirtualTerminalLevel /t REG_DWORD /d 1

11FAQ

Q: RTLens 和 Verible / svlangserver 有什么区别？

A: RTLens 是纯 Python 实现的轻量 LSP，零依赖、跨平台。Verible 是 C++ 实现（编译安装复杂），svlangserver 依赖 Java。RTLens 安装即用，额外提供了 REST API 和 MCP 接口让 AI agent 直接调用。

Q: 支持哪些 SystemVerilog 特性？

A: 支持 module 定义/例化、端口/参数/信号声明、always/initial 块、case/if-else、function/task、generate、typedef/enum/struct、\`include/\`define/\`ifdef 宏预处理。不支持 class 面向对象编程和 assertion。

Q: 可以处理大型工程吗？

A: 可以。默认限制最多索引 5000 个文件（可通过 max_files 参数调整）。索引使用线程安全设计，支持增量更新。

Q: 如何集成到 CI/CD 流程？

A: 使用 REST API 或 CLI 命令。例如：

# 索引工程并检查是否有未连接端口
python -m rtlens index ./rtl
curl http://127.0.0.1:8765/api/stats
curl "http://127.0.0.1:8765/api/module/top_module" | python -m json.tool

Q: 零依赖是什么意思？

A: 仅使用 Python 标准库（json, os, sys, http.server, cmd, threading, dataclasses, enum, re, urllib 等）。不需要 pip install 任何第三方包。

Q: 支持 eLinx / Anlogic FPGA 原语吗？

A: 支持。使用 --stub-dir 指定 eLinx 原语 stub 目录，即可在补全和悬停中显示原语端口信息。也支持解析 .pcf 约束文件。
